Entries save automatically in this browser. Save backup (JSON) restores everything later; Save spreadsheet (CSV) opens in Excel or Sheets. Load file accepts either. The file contains benefit names and eligible amounts only — no plan, member or claim details. Treat it as private, because benefit names can be sensitive.
